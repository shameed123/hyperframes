# AI Terms Explained Without Jargon

## Format

- Platform: YouTube Shorts
- Target length: 60 seconds
- Visual concept: Glossary popups
- Tone: Punchy, plain-English, friendly
- Working title: AI Terms Explained Without Jargon

## Script

| Time | Voiceover | Visual / Popup |
|---|---|---|
| 0-3s | AI words sound complicated. They're mostly just normal ideas wearing a lab coat. | Big text: "AI TERMS, PLAIN ENGLISH" |
| 3-7s | AI means software that can do tasks we usually associate with people, like writing, seeing, sorting, or deciding. | Popup: "AI = software that does smart tasks" |
| 7-12s | A model is the engine. It has learned patterns from tons of examples. | Popup: "Model = pattern engine" |
| 12-17s | An LLM, or large language model, is a model that predicts words really well. That's why it can chat. | Popup: "LLM = word prediction machine" |
| 17-22s | A prompt is your instruction. Better prompt, better answer. Like giving directions to a very fast intern. | Popup: "Prompt = your instruction" |
| 22-27s | Tokens are tiny chunks of text. Not always full words. The AI reads and writes in tokens. | Popup: "Tokens = text chunks" |
| 27-32s | The context window is the AI's short-term memory. If it gets full, older stuff falls out. | Popup: "Context window = short-term memory" |
| 32-37s | Training data is what helped teach the model. Inference is when it uses what it learned to answer you. | Popup: "Training = learning / Inference = answering" |
| 37-43s | A hallucination is when AI sounds confident but gets the facts wrong. Basically: fluent nonsense. | Popup: "Hallucination = confident mistake" |
| 43-49s | Embeddings turn meaning into numbers, so AI can find ideas that are similar, not just exact words. | Popup: "Embeddings = meaning as numbers" |
| 49-54s | RAG means the AI checks outside sources before answering, like open-book test mode. | Popup: "RAG = AI + reference material" |
| 54-59s | An agent is AI that can take steps: search, click, write, check, and keep going toward a goal. | Popup: "Agent = AI that takes actions" |
| 59-60s | That's the cheat sheet. AI is less magic when the words stop being weird. | End card: "Save this glossary" |

## Production Notes

- Keep on-screen captions to 3-5 words per beat.
- Treat each glossary popup as a visual anchor for the term being defined.
- Use quick, readable transitions between terms so the pace feels energetic without becoming overwhelming.
- Store all assets, drafts, generated media, and animation files for this video in this folder.
