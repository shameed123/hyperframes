# Visual Style

## Style Prompt

Build a bright, high-energy coding-agent short with a clean GitHub-inspired base, glass UI surfaces, crisp mono command chips, phone-scroll B-roll, and kinetic frame tiles. The visual tone should feel like a practical developer tool suddenly becoming magical: technical, fast, and clear, without becoming dark cyberpunk. Use a light canvas with deep ink text, GitHub black/gray accents, electric cyan for video understanding, fresh green for open-source/free, and warm amber for insight moments.

## Colors

- Background: `#f7fafc`
- Ink: `#0f172a`
- Muted text: `#526070`
- GitHub dark: `#24292f`
- Electric cyan: `#06b6d4`
- Open-source green: `#22c55e`
- Insight amber: `#f59e0b`
- Soft blue wash: `#dff5ff`

## Typography

- Display: `Arial Black`, `Impact`, `Inter`, sans-serif
- Body/UI: `Inter`, `Segoe UI`, sans-serif
- Code/labels: `IBM Plex Mono`, `Consolas`, monospace

## Motion Rules

- Use fast editorial entrances, diagonal slides, depth shadows, and 3D-ish tilts.
- Keep the GitHub mobile capture readable: no blur over repo title or install area.
- Captions use uppercase 3-5 word chunks with a cyan highlight accent.
- Avatar feature moments should feel intentional: large during hook and Codex emphasis, PIP during pipeline explanation.

## What Not To Do

- Do not make the whole video black-terminal themed.
- Do not cover captions with the avatar or phone b-roll.
- Do not use generic robot imagery.
- Do not depend on live network assets during render.
- Do not create one-note blue/purple visuals.
