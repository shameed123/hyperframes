# Thumbnail Prompt

Use case: 9:16 YouTube Shorts intro thumbnail for an AI coding-agent explainer.

Asset type: high-resolution vertical raster image, 1080x1920.

Primary request: Create an extremely eye-catching, scroll-stopping thumbnail about an open-source GitHub tool that lets AI coding agents watch videos. It should feel urgent, practical, and almost unbelievable at first glance.

Scene/backdrop: dramatic bright developer workspace with a giant tilted smartphone showing a GitHub-style repository page, video frames exploding out of the screen, a glowing command chip reading `/watch`, and visual analysis beams connecting frames to an AI coding-agent interface.

Subject: oversized video-frame grid, GitHub repository page, and a bold AI coding-agent interface motif. Add a surprised "AI agent eye" or lens-like analysis symbol, but no realistic person.

Style/medium: premium YouTube Shorts thumbnail, polished tech editorial, crisp UI, cinematic depth, glass panels, energetic but clean.

Composition/framing: 9:16 vertical. Huge headline in the top third, phone/repo in the center, video frames bursting diagonally toward the viewer, command chip and green GitHub badge near the bottom. Keep the headline unobstructed and readable on a phone.

Lighting/mood: bright, sharp, high contrast, excited, click-worthy, with a sense of "this changes everything."

Color palette: white and soft blue base, GitHub black/gray, electric cyan, open-source green, warm amber.

Text (verbatim): AI CAN WATCH VIDEOS

Secondary text (verbatim): FREE GITHUB SKILL

Constraints: headline and secondary text must be baked directly into the generated bitmap by the image model, huge, sharp, spelled exactly, and not clipped. Secondary text must be readable but smaller. Keep fake UI text generic except `/watch`. No text may be added later with HyperFrames, canvas, SVG, PowerShell, or local compositing.

Avoid: dark cyberpunk, purple-only gradient, tiny text, misspelled words, fake brand logos beyond generic GitHub-like styling, watermarks, clutter over the headline, realistic robot faces, extra random words.
