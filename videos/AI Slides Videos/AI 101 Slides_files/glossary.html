30 — Cheat sheet
Words you'll actually hear.
Model
The trained file of numbers. The "brain" itself.
LLM
Large Language Model — a model trained on huge text to predict words.
Prompt
Everything you give the model on a given turn — the input.
Token
The chunk a model reads/writes — roughly ¾ of an English word.
Context window
How many tokens the model can "see" at once. Its working memory.
Training
The one‑time process of teaching the model by adjusting its weights.
Inference
Running the trained model to produce an answer. What happens on Send.
Temperature
A dial from boring to brave. Low = factual; high = creative.
Hallucination
A confident, made‑up answer. The biggest gotcha — always verify.
Multimodal
A model that handles more than text — also images, audio, video.
Assistant
An app around an LLM (e.g. ChatGPT). Manages memory, UI, safety.
Agent
LLM + tools + a loop. It doesn't just answer — it acts.
Tool
A single action the model can call (search, send_email, …).
Skill
A reusable recipe — instructions + tools — for a recurring task.
MCP
A shared "plug" standard so any AI can use any external tool.
