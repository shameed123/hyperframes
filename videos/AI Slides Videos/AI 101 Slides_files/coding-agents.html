24 — Coding agents
Coding agents sit on a spectrum.
Some hide most of the code and give you a running app. Others live right inside your source code, terminal, pull requests, and tests.
High-level app builders
Describe the product. Get a working app.
Better for non-engineers, founders, internal tools, and quick prototypes. The platform often chooses the stack, generates the code, and handles deployment.
database auth hosting payments integrations
Examples: Lovable, Bolt.new, v0, Replit Agent, Firebase Studio, Base44.
Source-level coding agents
Work in the repo you already own.
Better for engineers and teams maintaining real codebases. The agent reads files, proposes diffs, runs commands/tests, and works through pull requests.
repo context diffs terminal tests pull requests
Examples: Claude Code, Codex, Antigravit, Cursor, Windsurf, GitHub Copilot, Devin, Junie, Cline.
Same loop underneath: plan → edit → run → observe → repair.
