23 — What agents use
Tools & skills — what's the difference?
🔧 Tool · a verb
A single action the model can perform.
Tools are functions with a name, a description, and a precise input shape. The model "calls" them when it needs to act on the real world.
search_web(query)
send_email(to, subject, body)
read_calendar(date_range)
Think: a button. One job, well‑defined.
📘 Skill · a playbook
A reusable recipe that uses tools.
Skills bundle instructions, examples, and the right combination of tools for a recurring task — so the agent doesn't reinvent it each time.
Schedule a meeting — read calendars, find a slot, send invites
Write a weekly report — pull metrics, draft summary, share doc
Triage support inbox — read mail, tag, reply, escalate
Think: a recipe card. Multiple steps, repeatable.
