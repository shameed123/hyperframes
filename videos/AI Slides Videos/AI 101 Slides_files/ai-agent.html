20 — AI agents
An agent does things,
not just says things.
The agent loop
STEP 1
Think
STEP 2
Pick a tool
STEP 3
Act
STEP 4
Observe → repeat
Example task: "Find me a flight to Tokyo under $900."

A chat assistant describes how to do it. An agent opens the browser, runs the search, compares prices across 3 sites, and replies with a chosen option — looping until the task is actually done.
Definition
An AI agent
=
LLM + tools + a loop.
The model decides what to do next; the tools let it actually do it.
