27 — MCP in the agent loop
With MCP, the agent talks to a server,
and the server talks to the service.
The agent stays focused on the task. MCP standardizes the connection: one server exposes a consistent interface while handling the details of a specific app, file system, database, or API.

What changed
The agent does not need a different integration pattern for every outside system.
It sends a standard MCP request across the network. The MCP server handles the service-specific details.
MCP makes development easier.
